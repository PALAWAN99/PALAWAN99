# 🎨 Logo & Favicon Design Specification

> **Concept:** Security, Technology, and Accessibility
> **Colors:** Navy Blue, Sky Blue, Emerald Green

---

## 🏗️ Design Rationale (แนวคิดการออกแบบ)

ตราสัญลักษณ์ของระบบ **QR Gate Access** ถูกออกแบบมาเพื่อสะท้อนถึงความปลอดภัยที่ทันสมัย (Modern Security) และความง่ายในการใช้งาน โดยมีองค์ประกอบหลัก 3 ส่วน:

### 1. 🟦 ฐานสี่เหลี่ยมมุมมน (Rounded Background)

- **สี:** Navy Blue (`#1E3A5F`)
- **ความหมาย:** ความมั่นคง (Stability), ความเป็นมืออาชีพ (Professionalism) และความน่าเชื่อถือในฐานะระบบควบคุมการเข้า-ออก

### 2. 💠 รูปแบบ QR Code (Stylized QR Pattern)

- **สี:** Sky Blue (`#38BDF8`)
- **ความหมาย:** การเชื่อมต่อ (Connectivity) และเทคโนโลยีสมัยใหม่ สื่อถึงฟังก์ชันหลักของระบบคือการใช้ Digital Key ในการเปิดประตู

### 3. 🟢 จุดมรกต (Emerald Pulse)

- **สี:** Emerald Green (`#10B981`)
- **ความหมาย:** "Access Granted" หรือ "Active" สื่อถึงสถานะที่ผ่านการตรวจสอบแล้ว และการมีชีวิตชีวาของระบบที่ทำงานแบบ Real-time

## 🎨 Color Palette (รหัสสีหลัก)

| สี | HEX | RGB | การใช้งาน |
| :--- | :--- | :--- | :--- |
| **Navy** | `#1E3A5F` | `30, 58, 95` | พื้นหลัง, Header, ข้อความหลัก |
| **Sky** | `#38BDF8` | `56, 189, 248` | ไอคอน, ลิงก์, ปุ่ม Interactive |
| **Emerald** | `#10B981` | `16, 185, 129` | สถานะผ่าน (Success), ปุ่มยืนยัน |
| **White** | `#FFFFFF` | `255, 255, 255` | พื้นหลังหน้าจอ (Light Mode), ข้อความบนพื้นเข้ม |

## 📑 Asset Checklist

### 1. Main Logo (`/public/logo.png`)

- รูปทรงสี่เหลี่ยมจัตุรัสมุมมน
- ใช้บนหน้า Landing Page และหน้า Login
- สัดส่วนสมดุลเพื่อความชัดเจนบนหน้าจอทุกขนาด

### 2. Favicon (`/public/favicon.svg`)

- ไฟล์ SVG เพื่อความคมชัดสูงสุด (Vector)
- ตัดทอนรายละเอียดเพื่อให้มองเห็นได้ชัดในขนาด 16x16 หรือ 32x32 pixels บน Browser Tab

### 3. Apple Touch Icon (`/public/apple-touch-icon.png`)

- สำหรับการบันทึกเป็น Shortcut บนหน้าจอโฮมของ iOS/Android
