# การสำรองและกู้คืนข้อมูล (Backup & Restore Guide)

ระบบจัดการประตูห้องสมุดมีความสำคัญสูง ข้อมูลสมาชิกและประวัติการเข้า-ออกต้องได้รับการสำรองข้อมูลอย่างสม่ำเสมอ

## 1. วิธีการสำรองข้อมูล (Backup)

### 1.1 การใช้สคริปต์อัตโนมัติ (PowerShell)
เราเตรียมสคริปต์ `scripts/db-backup.ps1` ไว้ให้สำหรับ Windows:
1. เปิด PowerShell
2. รันคำสั่ง:
   ```powershell
   ./scripts/db-backup.ps1
   ```
3. ไฟล์สำรองจะถูกเก็บไว้ในโฟลเดอร์ `backups/`

### 1.2 การสำรองข้อมูลด้วยตนเอง
- **SQLite:** คัดลอกไฟล์ `dev.db` (หรือตามที่ระบุใน .env) ไปเก็บไว้ที่ปลอดภัย
- **PostgreSQL:** ใช้คำสั่ง `pg_dump`:
  ```bash
  pg_dump -U [username] -d [dbname] > backup_file.sql
  ```

---

## 2. การกู้คืนข้อมูล (Restore)

### 2.1 สำหรับ SQLite
1. ปิดแอปพลิเคชัน
2. เปลี่ยนชื่อไฟล์สำรองเป็นชื่อไฟล์หลัก (เช่น `dev.db`)
3. นำไปวางในตำแหน่งเดิม

### 2.2 สำหรับ PostgreSQL
ใช้คำสั่ง `psql`:
```bash
psql -U [username] -d [dbname] < backup_file.sql
```

---

## 3. ข้อแนะนำในงานจริง (Production)

1. **Automation:** ตั้งค่า Windows Task Scheduler หรือ Cron Job ให้รันสคริปต์สำรองข้อมูลทุกวันเวลา 00:00 น.
2. **Off-site Backup:** ไม่ควรเก็บไฟล์สำรองไว้ในเครื่องเดียวกับ Server ควรมีการอัปโหลดขึ้น Cloud Storage (เช่น S3, Google Drive) หรือ NAS ของหน่วยงาน
3. **Retention Policy:** ควรเก็บข้อมูลสำรองย้อนหลังอย่างน้อย 30 วัน
4. **Test Restore:** ควรทำการทดสอบกู้คืนข้อมูล (Restore Test) อย่างน้อยเดือนละครั้ง เพื่อให้มั่นใจว่าไฟล์สำรองใช้งานได้จริง
